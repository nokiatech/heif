# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in the Nokia HEIF library,
please report it by emailing **heif@nokia.com** with subject line
`SECURITY: [brief description]`.

Please include:
- A description of the vulnerability
- Steps to reproduce (or a proof-of-concept file)
- The version of the library affected

Please do **NOT** file a public GitHub issue for security vulnerabilities.
