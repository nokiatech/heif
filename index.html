About HEIF
HEIF is an ISOBMFF based container format for storage of encoded media.
Supports codecs like AVC and HEVC - along with VVC, the latest codec in the family, to provide high quality media with good compression ratio.
Image dimensions: 1440x960, file size: 127 KiB
Multiple Images, One File
HEIF can store bursts, collections, and animations in a single container — no zips, no sidecar files. Every frame shares the same metadata and codec efficiency.
Image dimensions: 1440x960, file size: 40 KiB
Non-Destructive Editing Built In
Grids, overlays, rotations, and crops are expressed as lightweight references — the original pixels are never touched. Alpha planes and depth maps ride alongside the primary image.
